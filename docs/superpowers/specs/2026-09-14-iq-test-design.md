# IQ 测试 — 设计文档

日期：2026-09-14
状态：设计已获用户批准，待实现
模块 id：`iq`　中文名：IQ 测试（id 与路由前缀统一为 `Iq`）

## 背景

FlowKit（流光）新增「IQ 测试」模块，面向个人自测与朋友分享，覆盖儿童（6 岁起）与成人，提供两档形态：**专业模拟版**（多维度、分维度报告）与**轻量趣味版**（短时、趣味评价）。

### 专业调研结论（决定设计边界）

临床（精神心理科 / 发育行为科 / 儿保科）在用的智力测验主要为：

| 工具 | 适用年龄 | 结构 |
|---|---|---|
| 韦氏幼儿 WPPSI-IV 中文版 | 2岁半–7岁7个月 | 言语理解 / 视觉空间 / 流体推理 / 工作记忆 / 加工速度 |
| 韦氏儿童 WISC-IV/V 中文版 | 6–16岁11个月 | 言语理解 / 知觉推理 / 工作记忆 / 加工速度（V 版增视觉空间） |
| 韦氏成人 WAIS-IV 中文版 | 16–90 岁 | 言语理解 / 知觉推理 / 工作记忆 / 加工速度（4 指数、10 核心分测验） |
| 斯坦福-比奈第五版 | 2–85 岁 | 流体推理 / 知识 / 数量推理 / 视觉空间 / 工作记忆 |
| 瑞文系列（CPM / SPM / APM / 联合型 CRT 国内修订） | 5–75 岁 | 单一流体推理（非言语） |
| 0–6 岁发育筛查（儿心量表 / Gesell / DDST） | 0–6 岁 | 发育商 DQ 体系，非 IQ 测试 |

由此确定四条不可动摇的设计边界：

1. **版权约束**：上述工具全部受版权保护，网络流传题目亦不可照搬。本模块**完全自研原创题目**，仅借鉴临床量表的维度结构与题型范式（不复制任何原题）。
2. **定位诚实**：App 自测受环境、设备、动机、练习效应影响，无法替代标准化施测。输出定位为「认知能力自测参考」，所有报告页必须显式声明**非诊断用途**；儿童报告使用克制措辞。
3. **题型公平**：跨年龄、跨教育背景最公平的是非言语流体推理（矩阵/序列），作为主维度；言语类比为辅助维度并为低龄段提供 TTS 朗读；工作记忆与加工速度采用可触屏忠实还原的经典范式（数字广度、符号检索）。
4. **无实测常模**：折算表为**设计标定**（基于题目难度模型与正态假设构建），非实测常模；结果输出**估算区间**而非精确点值，避免伪精确。

参考：WAIS-IV 中文版（中国行为科学社）、联合型瑞文测验（国内修订）、瑞文标准推理测验在我国的修订（心理学报）、韦氏成人智力量表第四版中文版信度与结构效度研究。

## 需求范围

### 一期包含

- 两种模式：**专业模拟版**（四维度、约 30–35 分钟、约 70 作答点）与**轻量趣味版**（约 5–8 分钟、12 题 + 30 秒速配）
- 四档年龄（6–8 / 9–11 / 12–16 / 17+）各固定卷面，共享题池
- 专业版四维度：流体推理 / 言语类比 / 工作记忆 / 加工速度
- 报告：IQ 估算区间 + 百分位 + 四维条形画像 + 文字解读 + 免责声明（成人/儿童措辞不同）
- 历史记录：结果入库（上限 100 条），同档复测对比，回看报告，删除 / 清空
- 低龄段（6–8）言语题 TTS 朗读（Android）；练习环节；家长陪测提示
- 全离线、双端启用（`enabled: true`）

### 明确不做（YAGNI）

- 自适应施测（基线—天花板路由）—— 二期演进，题目数据模型已预留难度标签
- 断点续测（中途退出丢弃进度；临床施测本就连续完成）
- 真实常模采集与标定
- 成绩分享卡片 / 导出
- 雷达图（一期用条形画像）
- 学前（<6 岁）版本（属发育筛查 / DQ 体系，是另一套工具）

## 试卷设计

### 两版总体结构

| | 专业模拟版 | 轻量趣味版 |
|---|---|---|
| 时长 | 约 30–35 分钟 | 约 5–8 分钟 |
| 题量 | 约 70 作答点（见下） | 12 题 + 30 秒速配 |
| 维度 | 流体推理 / 言语类比 / 工作记忆 / 加工速度 | 流体推理 + 加工速度（短版） |
| 年龄 | 四档独立卷：6–8 / 9–11 / 12–16 / 17+ | 同四档（同一题池抽取） |
| 报告 | IQ 估算区间 + 百分位 + 四维画像 + 文字解读 | 星级档位 + 趣味评语，不报数字 IQ |
| 结果入库 | 是 | 是 |

**专业版卷面构成**

| 维度 | 题量 | 形式 | 计时 |
|---|---|---|---|
| 流体推理 | 28 | 矩阵推理 20（3×3，六选一）+ 图形序列 8 | 不限时 |
| 言语类比 | 14 | A : B ＝ C : ?，四选一 | 不限时 |
| 工作记忆 | 上限 14–22 试 | 数字顺背 + 倒背（每长度 2 试，两试皆错终止） | 闪示节奏固定 |
| 加工速度 | 1 个任务 | 符号检索：90 秒内连答「有 / 无」 | 90 秒硬限时 |

### 四维度题目设计

#### ① 流体推理（28 题）

- 矩阵推理 20 题：3×3 矩阵、缺 1 格、六选一；规律类型按难度分层：数量递进 → 旋转/对称 → 叠加消去（XOR）→ 图形移动/组合
- 图形序列 8 题：横向序列预测下一项
- 图形由结构化 `ShapeSpec` 描述（见数据模型），**无图片素材**
- 不限时；正式题**不给对错反馈**（临床标准，练习环节除外）

示例（难度 2/10，每行图形数量按列递增，答案 ▲▲▲）：

```
┌─────┬─────┬─────┐
│  ●  │ ●●  │ ●●● │
├─────┼─────┼─────┤
│  ■  │ ■■  │ ■■■ │
├─────┼─────┼─────┤
│  ▲  │ ▲▲  │  ?  │
└─────┴─────┴─────┘
```

示例（难度 6/10，每行图形顺时针旋转 90°，答案 ↑）：

```
┌─────┬─────┬─────┐
│  ↑  │  →  │  ↓  │
├─────┼─────┼─────┤
│  ←  │  ↑  │  →  │
├─────┼─────┼─────┤
│  ↓  │  ←  │  ?  │
└─────┴─────┴─────┘
```

#### ② 言语类比（14 题）

- 格式：A : B ＝ C : ?，四选一；关系类型：反义 / 种属 / 功能 / 部分-整体 / 程度 / 因果
- 每题保证**唯一正确关系**；干扰项为「表面相似陷阱」，不产生歧义（如答案为「大海」时以「河流」做同类陷阱）
- 6–8 档默认 **TTS 朗读题面**（口头呈现即临床言语分测验的标准方式）；9+ 档可手动点朗读按钮
- 低龄段词汇限定在小学低年级词表范围

示例（低龄段）：鸟 : 巢 ＝ 蜂 : ?（蜂蜜 / 蜂巢 / 花朵 / 翅膀）→ 蜂巢
示例（成人段）：怀疑 : 确信 ＝ 小溪 : ?（沙滩 / 大海 / 河流 / 雨滴）→ 大海（程度/规模递进）

#### ③ 工作记忆 — 数字广度

- 顺背 + 倒背；屏幕逐位闪示数字（每位显示 700ms、间隔 250ms）
- 数字键盘作答 + 「提交」按钮；**不显示目标长度**（避免泄漏难度）
- 每个长度 2 试、**两试皆错即终止**（临床天花板规则的微型版，同时防止儿童受挫）
- 起始长度与上限随年龄档：

| 年龄档 | 顺背长度 | 倒背长度 | 试数上限 |
|---|---|---|---|
| 6–8 | 3–6 | 2–4 | 14 |
| 9–11 | 3–7 | 2–5 | 18 |
| 12–16 | 4–8 | 3–6 | 18 |
| 17+ | 4–9 | 3–7 | 22 |

示例：顺背 5 位「7 3 9 1 4」→ 作答 7 3 9 1 4；倒背 3 位「5 2 8」→ 作答 8 2 5

#### ④ 加工速度 — 符号检索（90 秒）

- 顶部固定目标符号；行流逐行呈现，每行 5 个符号；快速点「有 / 无」
- 计分 = 净正确数（正确 − 错误）
- 行流**预生成固化**（约 120 行，90 秒到即截断），不做运行时随机
- 跨年龄共用同一任务（本质是速度而非难度），计分按年龄档折算

示例：目标 ◆，出现行「● ■ ▲ ◆ ★」→ 点「有」

### 练习环节

- 每维度正式计分前 1–2 题**不计分练习**（临床标准做法）：练习答错给提示并可重来，正式题不给反馈
- 练习题固定入库（练习池），言语练习 1 题、矩阵练习 2 题、记忆练习 1 题（仅顺背）、速度练习 1 题

### 年龄适配策略

- 四档（6–8 / 9–11 / 12–16 / 17+）各固定卷面：**同档复测可比，跨档不直接比**（报告与结果页注明）
- 6–8 档言语题默认朗读；进入前提示家长陪测规则（可代读题面、不可提示答案）
- 儿童报告措辞克制（「认知发展参考」），成人报告可比性说明更强

### 计分与报告口径

- **维度原始分**：
  - 流体 / 言语：难度加权答对和（答对得该题难度分，答错 0）
  - 记忆：最长通过长度（主导）+ 通过试数（微调），顺背倒背分别计后合成
  - 速度：净正确数（正确 − 错误）
- **折算**：四档年龄各一张折算表 → 维度指数（M=100、SD=15 口径）
- **总分**：四维加权平均 → 输出 **IQ 估算区间**（点值 ±7.5，如 108–123）+ 百分位参考（正态假设换算）
- 折算表为**设计标定、非常模**；报告固定标注「自测参考，非医学诊断，不能替代专业评估」
- 结果页结构：总分区间 → 百分位条 → 四维度条形画像（纯 View 实现，不引图表库）→ 逐维度一句解读 → 免责声明（成人/儿童两版文案）→ 历史入口
- **轻量版**：星级档位（1–5 星）+ 趣味评语模板，**不报数字 IQ**（避免伪精确）；结果页引导「挑战专业版」

### 题库规模与组卷规则

- 流体池 ≈ 40（矩阵 28 + 序列 12），四档卷面各取 28，相邻档重叠约 60–70%
- 言语池 ≈ 24，各档卷面 14（按年龄段标签选取）
- 记忆序列库：固定序列（非随机），按长度组织、每长度多组备用
- 速度任务：固定目标符号 + 固定行流
- 轻量卷：流体池抽 12 题（难度 2–7 覆盖）+ 30 秒速配（同一符号体系短版）
- **组卷确定性**：无随机、同输入同输出（禁止 `Math.random`），保证复测可比、测试可断言

### 关键工程决策

1. **图形渲染零新依赖**：矩阵题图形用结构化数据 + **Unicode 几何符号白名单**渲染（●○■□▲△◆◇★☆↑↓←→），旋转用 `transform`，线条类基元由绝对定位 View 绘制。不引入 `react-native-svg`（避免重编译原生工程；emoji 模块引入 clipboard 时的既有教训）。代价：图形基元限定白名单，题库设计须遵守（`itemBank.test.ts` 校验）。
2. **确定性组卷**：`paperBuilder` 按「难度排序 + 固定选取规则」从题池生成四档卷面，任何设备任何次运行结果一致。
3. **计分引擎纯函数**：`scoring.computeResult(responses, paper, ageBand)` → 维度原始分 → 折算表 → 维度指数 + 总分区间 + 百分位；折算表为数据文件，注释写明「设计标定、非常模」性质。
4. **会话不持久化**：中途退出 = 确认弹窗 → 丢弃进度；结果仅在完成时写入 AsyncStorage。

## 页面与交互

### IqHomeScreen（入口）

- 模式选择：两个大卡片（专业模拟版 / 轻量趣味版），各带时长与内容说明
- 年龄选择：四档按钮（6–8 / 9–11 / 12–16 / 17 岁及以上）
- 选择完成后「开始测试」；导航栏右上角 → 历史记录
- 页面底部或折叠区：测试说明与免责声明入口

### IqTestScreen（施测流程）

- 顶部显示当前维度名与维度内进度（如「言语类比 3/14」）；**不显示跨维度总进度**（临床惯例，减少预期干扰）
- 按 section 顺序推进：练习（不计分、答错给提示）→ 正式题逐题作答
- 选择题：点选后**无对错反馈**，直接进入下一题
- 记忆段：闪示 → 数字键盘作答 → 天花板判定
- 速度段：3-2-1 倒计时 → 90 秒作答 → 自动结束
- 完全不相交的题型间插入过渡说明页（如「接下来：凭记忆按顺序点出数字」）
- 返回按钮 → 退出确认弹窗（丢弃进度）

### IqResultScreen（报告页）

- 渲染 `TestResult`（新完成的结果或从历史复用的记录）
- 专业版：总分区间大字 → 百分位条 → 四维条形画像 → 逐维解读 → 免责 → 「查看历史」
- 轻量版：星级 + 评语 → 「挑战专业版」/「再测一次」→ 免责

### IqHistoryScreen（历史）

- 列表项：模式 / 年龄档 / 总分区间（轻量版为星级）/ 完成时间
- 同档相邻两条自动对比（区间升降箭头）；点击条目 → 报告页回看
- 删除单条、「清空全部」带二次确认（沿用 emoji 历史页交互）

## 施测状态机与数据流

```
IqHome（选模式 / 年龄）
  → paperBuilder 取固定卷面 → 初始化 session（zustand）
  → IqTestScreen 按 section 推进：
      练习（不计分）→ 正式题逐题作答
      记忆段：固定节奏闪示 → 键盘作答 → 两试皆错终止
      速度段：3-2-1 倒计时 → 90 秒行流 → 自动结束
  → scoring.computeResult → resultStorage 落库 → IqResultScreen
```

- 作答记录含每题用时（仅作报告参考，不参与计分）
- 记忆段闪示节奏固定，不随作答表现变化

## 数据模型（要点）

```ts
type AgeBand = '6-8' | '9-11' | '12-16' | 'adult';
type Dimension = 'fluid' | 'verbal' | 'memory' | 'speed';

// 图形基元（白名单渲染）
type ShapeKind = 'circle' | 'square' | 'triangle' | 'diamond' | 'star' | 'arrow' | 'line';
interface ShapeSpec {
  kind: ShapeKind;
  fill: 'solid' | 'hollow';   // line 基元忽略
  count: number;              // 同格内重复个数
  rotation?: 0 | 90 | 180 | 270;  // arrow / line 等
  size?: 'small' | 'large';
}

interface ChoiceResponse { kind: 'choice'; itemId: string; optionIndex: number; elapsedMs: number }
interface MemoryResponse { kind: 'memory'; trialId: string; input: number[]; elapsedMs: number }
interface SpeedResponse  { kind: 'speed'; correct: number; wrong: number }
type Response = ChoiceResponse | MemoryResponse | SpeedResponse;

interface TestResult {
  id: string;
  mode: 'pro' | 'light';
  ageBand: AgeBand;
  createdAt: number;
  durationMs: number;
  report:
    | { kind: 'pro'; dimensionIndices: Record<Dimension, number>;
        total: { iqLow: number; iqHigh: number; percentile: number } }
    | { kind: 'light'; starLevel: number; summary: string };
}
```

- 存储 key：`@flowkit:iq:results`，上限 100 条，超出淘汰最旧
- 各题型数据结构（MatrixItem / VerbalItem / MemoryTrial / SpeedRow）在 `types/` 中定义并注释

## 边界处理

| 场景 | 处理 |
|---|---|
| 施测中返回 / 杀进程 | 退出确认弹窗，丢弃进度（不做断点续测） |
| 速度 / 闪示段退到后台 | AppState 监听 → 暂停；回前台 3 秒倒计时后继续（保证计时公平） |
| 儿童 TTS 朗读 | Android 复用现有 `NativeModules.TtsModule`；iOS 一期降级为「家长代读」提示文案 |
| 大字号 / 无障碍 | 图形题固定尺寸；文本题尊重系统字号；报告页验证大字号不破版 |
| 网络 | 全离线，无网络路径，不做加载失败兜底 |

## 实现注意事项

- **题库生成管线**（开发期一次性）：题目批量设计（AI 生成 + 人工审查）→ `itemBank.test.ts` 自动校验 → 抽检；题库为静态数据文件直接入库
- **Unicode 白名单**：渲染前先做真机截图验证字体覆盖；不达标的符号从白名单剔除并调整题库
- **折算表**：数据文件带注释说明设计标定方法（题目难度模型 + 正态假设），禁止表述为「常模」
- **TTS**：复用 trigger 模块的 `NativeModules.TtsModule`（Android）；中文可懂度需真机试听，rate / pitch 取默认值起步
- **计时公平**：速度段与闪示段必须接入 AppState 暂停逻辑；RN Timer 在后台不可靠，恢复时以剩余时间重建
- **组卷纪律**：任何组卷、序列、符号行流数据禁止运行时随机（确定性是可测试性与复测可比性的基础）
- **免责文案**：成人 / 儿童两版固定文案，结果页与首页说明处均出现，实现时逐字评审
